# Credit Card Fraud Detection

## Overview
This project focuses on identifying fraudulent credit card transactions using machine learning. Given the highly imbalanced nature of fraud datasets, this notebook explores techniques to handle class imbalance and accurately classify anomalies.

## Dataset
The dataset is sourced from Kaggle and contains anonymized credit card transactions labeled as fraudulent or genuine.

## Key Techniques
* Exploratory Data Analysis (EDA)
* Handling imbalanced data (e.g., SMOTE, class weighting)
* Classification modeling (e.g., Random Forest, Logistic Regression)
* Performance evaluation using Precision, Recall, and F1-Score

## How to Run
1. Install dependencies: `pip install pandas numpy scikit-learn matplotlib seaborn`
2. Open `credit_card_fraud.ipynb` in Jupyter Notebook or JupyterLab.
3. Run all cells sequentially.
