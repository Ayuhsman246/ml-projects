# Loan Prediction Analysis

## Overview
This project builds a predictive model to determine whether a loan applicant will be approved or rejected based on their demographic and financial profile. 

## Dataset
The dataset is sourced from Kaggle and includes applicant details such as gender, marital status, education, income, and credit history.

## Key Techniques
* Data preprocessing and missing value imputation
* Categorical feature encoding
* Exploratory Data Analysis (EDA)
* Predictive modeling to automate loan eligibility decisions

## How to Run
1. Install dependencies: `pip install pandas numpy scikit-learn matplotlib seaborn`
2. Open `loan_prediction.ipynb` in Jupyter Notebook or JupyterLab.
3. Run all cells sequentially.
